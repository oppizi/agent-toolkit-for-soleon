Soleon Agent Toolkit MCP

Manage Soleon agents from any MCP client — list and inspect agents, edit and publish custom tools, bind channels, and read evals, traces, and usage. Tools are served live from the platform: install once, and new capabilities appear automatically.

28 tools live 3 pending Cognito bearer auth Claude Code plugin

Install

/plugin marketplace add oppizi/agent-toolkit-for-soleon
/plugin install soleon-deploy-agent@agent-toolkit-for-soleon

On install you'll be prompted for a Soleon access token (stored in your system keychain, injected at connect time). Tokens are short-lived — reconfigure the plugin to rotate.
